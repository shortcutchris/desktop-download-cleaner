# Desktop Cleaner 1.2.0

Desktop Cleaner now speaks German and English throughout the complete app.

## What’s new

- Switch between **System Default**, **English**, and **Deutsch** in **Settings → General → Language**.
- The change is immediate across the main window, Settings, menu bar, app commands, status messages, errors, notifications, and local classification explanations.
- OpenAI metadata proposal reasons follow the selected language while continuing to send metadata only.
- The localization layout is ready for future languages through one language entry and one resource bundle.

## Safety and privacy

Changing the interface language never renames files or rewrites category directories, saved rules, plans, transaction journals, or rollback paths. No file-content or AI privacy boundary changed in this release.

## Release integrity

- Universal Apple Silicon and Intel build.
- Developer ID signed and Apple notarized.
- Protected by Desktop Cleaner’s dedicated Sparkle EdDSA signature.
