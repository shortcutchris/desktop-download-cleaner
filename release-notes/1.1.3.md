# Desktop Cleaner 1.1.3

Desktop Cleaner 1.1.3 fixes update installation from the sandboxed application.

## Fixed

- Enabled Sparkle's required Installer Launcher XPC service.
- Added the two documented Mach-service exceptions used by Sparkle's installer.
- Added release-time validation so a misconfigured sandboxed updater cannot be published again.

No cleanup behavior or file-safety invariant changes in this patch.
