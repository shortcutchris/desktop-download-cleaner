# Desktop Cleaner 1.1.1

Desktop Cleaner 1.1.1 activates the signed Sparkle update path for the public release channel.

## Highlights

- Check for new releases manually from Settings or the application menu.
- Opt in to automatic checks; they remain off by default.
- Verify every downloaded update with Desktop Cleaner's dedicated Sparkle EdDSA key.

No cleanup behavior or file-safety invariant changes in this patch.
