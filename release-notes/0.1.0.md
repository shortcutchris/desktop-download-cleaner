# Desktop Cleaner 0.1.0 development milestone

This internal milestone establishes the native macOS project and the safe local planning core. It is not an externally published release.

## Included

- Read-only, depth-limited scanning for explicitly authorized source folders.
- Deterministic categories, sensitive-file defaults, and user exclusion patterns.
- Filename normalization that preserves extensions.
- Case-insensitive collision handling with relative destinations below a review session.
- A minimal runnable app shell, disabled Sparkle development integration, CI, and automated tests.

## Privacy and safety

No AI integration is active, no file contents leave the Mac, and scanning or planning never creates, renames, moves, copies, or deletes source files. Integration tests use isolated temporary directories rather than Desktop or Downloads.
