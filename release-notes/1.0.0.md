# Desktop Cleaner 1.0.0

Desktop Cleaner 1.0 turns accumulated files into a reviewable cleanup plan before anything moves.

## Highlights

- Scan user-authorized Desktop, Downloads, or custom folders without modifying them.
- Review deterministic categories and safe filename suggestions in a polished native macOS workspace.
- Approve only selected items, stage them in a visible review folder, and undo the complete session—even after restarting the app.
- Create ordered local rules for repeated cleanup choices.
- Optionally request metadata-only OpenAI suggestions with an exact request-scope preview and a Keychain-stored user API key.
- Use a menu bar entry point, launch at login, notifications, and safe app-data reset.

## Safety and privacy

Desktop Cleaner never automatically deletes files and never overwrites an existing destination. AI is off by default. The 1.0 AI capability sends metadata only after a visible confirmation; sensitive files, file contents, absolute paths, previews, commands, and approval decisions are excluded.

This repository is currently private. These notes describe the release-ready 1.0 build; an external GitHub release is published only after explicit authorization and successful signing, notarization, appcast verification, installation, and launch checks.
