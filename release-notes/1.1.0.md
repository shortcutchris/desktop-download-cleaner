# Desktop Cleaner 1.1.0

Desktop Cleaner 1.1 completes the configurable local organization workflow while preserving the same strict safety boundary: scans and plans are read-only, staging requires explicit approval, existing files are never overwritten, and nothing is automatically deleted.

## Highlights

- Detect identical eligible files locally by hashing only same-size candidates; hashes and file contents are never persisted or transmitted.
- Sort proposals and select multiple rows for safe batch approval or rejection. Low-confidence and sensitive items stay out of batch approval.
- See the exact relative destination, proposal origin, privacy scope, and collision resolution for every item.
- Resume the current plan after relaunch, while a completed staging transaction consumes that plan to prevent accidental replay.
- Drag individual organized files from a staged or retained session into Finder or another compatible Mac app.
- Configure naming separators, detected date normalization, collision suffixes, AI reasoning quality, menu-bar presence, and finalized-session history retention.
- Preview the exact redacted diagnostics JSON before exporting it. The report cannot contain filenames, paths, contents, API-key values, or model payloads.
- Developer-ID signing covers Sparkle's embedded helpers with secure timestamps so the complete bundle passes Apple notarization.
- A dedicated Sparkle Ed25519 public key verifies signed Desktop Cleaner update archives; its private counterpart remains only in macOS Keychain.

## Validation boundary

The release is Developer-ID signed, Apple-notarized, stapled, and tested on macOS. Its GitHub release includes the universal app archive, SHA-256 checksum, and signed Sparkle appcast.
