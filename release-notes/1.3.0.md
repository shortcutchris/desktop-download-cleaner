# Desktop Cleaner 1.3.0

Desktop Cleaner now includes a complete offline Help center in German and English.

## What’s new

- Open **Help & Guide** from onboarding, the review toolbar, Settings, the menu bar, or the macOS Help menu with **Command-?**.
- Search practical articles for setup, reviewing proposals, staging and undo, privacy, optional OpenAI assistance, rules, exclusions, shortcuts, and troubleshooting.
- Practice the full workflow in an interactive guided tour with clear steps and safety reminders.
- Switch the app language in Settings and Help updates immediately with the rest of the interface.
- Review every release under **Settings → Changelog**, organized by new features, improvements, fixes, and security changes.
- Use the version and build summary at the bottom of the main window to jump directly to the current changelog.

## Safety and privacy

The guided tour is a pure offline simulation. It requests no folder access and never scans, creates, renames, copies, moves, deletes, persists, or transmits files or user data. The app’s existing approval, transaction, rollback, Keychain, and metadata-only AI boundaries are unchanged.

## Release integrity

- Universal Apple Silicon and Intel build.
- Developer ID signed and Apple notarized.
- Protected by Desktop Cleaner’s dedicated Sparkle EdDSA signature.
